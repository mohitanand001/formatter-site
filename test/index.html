Morph test build 0.15.0-rc.1

For GNOME on Linux (Ubuntu, Fedora Workstation). Install with one line:

curl -fsSL https://mohitanand001.github.io/formatter-site/test/install.sh | bash

Prefer to read it first? install.sh only downloads this zip, checks its fingerprint against version.json, unpacks it into ~/.local/share/morph and runs morph --install. No sudo.

When it finishes, Morph opens a short setup page with two questions: which apps it may read copies from, and whether to check for updates. It reads nothing until you answer. No log out is needed. Only if the installer says so, log out and back in once.

Optional: read tables from images

Copy a screenshot of a table, then click an app in the pill: Morph reads the rows and columns and converts them like any other table. It runs PaddleOCR on your computer and only when you click. Turn it on in a terminal (about 1 GB, one time, needs internet):

~/.local/bin/morph --enable-ocr

Remove it with morph --disable-ocr. OCR can misread digits, so check the numbers.

Remove it any time with morph --uninstall.
