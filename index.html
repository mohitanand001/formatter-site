Formatter

Copy once. Paste right, anywhere.

Formatter sits on the edge of your screen and converts what you copied for Slack, Jira, Confluence, Docs, Email, Markdown and more, so the formatting survives the paste.

Install on Linux

A tiny download that uses what GNOME already has: no Node.js, no Electron, nothing else to fetch. Made for Ubuntu and other GNOME desktops on Wayland.

You need

Ubuntu, Fedora Workstation or another GNOME desktop, and unzip. GNOME's gjs is already part of it.

What it adds

The pill on your screen edge, a small GNOME helper, and a formatter-linker command. No icon in the top bar.

What it reads

The clipboard and the front window's app name and title, only on your computer. Nothing is sent anywhere.

1

Unpack the folder

Download formatter-0.14.0-rc.2-linux.zip, put it in your home folder (move it from Downloads), then unpack it.

cd ~
unzip formatter-0.14.0-rc.2-linux.zip
cd formatter
2

Run the installer

It takes a second. It adds the formatter-linker command, the GNOME helper and start-at-login. It also stops the older Electron version if you had it.

chmod +x bin/formatter-linker
bin/formatter-linker --install
3

Log out and back in

GNOME on Wayland only loads a new helper at login, so this is needed once. Formatter starts by itself after that.

Don't skip it. Without it the pill won't appear.
You should see a notification saying Formatter is running, and a slim tab on the right edge of the screen. Check with formatter-linker --status.
4

Use it

Copy something in an app you've chosen, click the tab, pick where it's going, then paste with Ctrl+V. The pill never takes focus, so the paste lands where you were.

Update

Unpack the new zip over the old folder, then run the installer again. Log out and in only if it says the helper changed.

cd ~
unzip -o formatter-0.14.0-rc.2-linux.zip
cd formatter
bin/formatter-linker --install
formatter-linker --restart

Uninstall completely

One command removes the start-at-login entry, the command and the GNOME helper. Then delete the folder and, if you like, your settings.

1

Remove it from this account

formatter-linker --uninstall
sed -i '/formatter-linker PATH/,+1d' ~/.bashrc

The second line takes out the path line the installer may have added to ~/.bashrc.

2

Remove your settings and the folder

Settings are your chosen apps, order and size. Skip the first line if you plan to reinstall and want them back.

rm -rf ~/.config/formatter ~/.config/format-bridge "$HOME/.config/Format Bridge" ~/.cache/formatter.log ~/.cache/formatter-linker.log
rm -rf ~/formatter
3

Log out and back in

GNOME keeps the old helper loaded until you do. Afterwards the tab is gone.

gnome-extensions info format-bridge-focus@formatbridge.dev   # should say: not found

Try it on a fresh user

A second Linux user behaves like a new machine: no settings, no helper, no command. Both sessions can stay open side by side.

1

Create the test user

From your normal account. Pick any password.

sudo adduser formattertest
2

Share the zip

Put it where both users can read it.

cp ~/formatter-0.14.0-rc.2-linux.zip /tmp/
chmod 644 /tmp/formatter-0.14.0-rc.2-linux.zip
3

Sign in as that user

Use the user menu in the top right, choose Log Out or switch user, and sign in as formattertest on a normal graphical login, not a terminal. Copy the zip from /tmp into the new user's home folder, then follow Install above.

The first thing to look for: everything should start from zero. If you see your old chosen apps, you're still in your own account.
4

Clean up afterwards

From your normal account, once you've finished testing. This deletes the test user and its files.

sudo deluser --remove-home formattertest

Troubleshooting

The pill doesn't appear

You need to log out and in once after installing. Then run formatter-linker --status. If the helper isn't active, run gnome-extensions enable format-bridge-focus@formatbridge.dev and log out and in again.

The pill only shows in the apps you've chosen. Open its settings (the gear) and switch on "Show the pill in every app" to see it everywhere.

I closed the pill with the ✕

Press Ctrl Alt F, or log out and in. It always comes back at the next start.

"gjs is missing"

It's part of GNOME, so this is rare. On Ubuntu run sudo apt install gjs, on Fedora sudo dnf install gjs.

It stops right away

Run formatter-linker --start. It prints the last lines of its log if it can't start. Attach them when you report a problem.

Where does it log?

In ~/.cache/formatter.log. For more detail, run FB_DEBUG=1 gjs -m ~/formatter/daemon/gjs-main.js in a terminal.
